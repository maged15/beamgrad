# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful and constructive, keep discussion focused on the work,
and do not harass anyone. Harassment, abuse and discriminatory behaviour are
not tolerated.

Report unacceptable behaviour privately to the maintainer through the contact
details on the [maintainer's GitHub profile](https://github.com/maged15).
Reports will be handled confidentially.
